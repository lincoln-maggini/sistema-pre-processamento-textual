# Sistema de Pré-processamento Textual para Mineração de Textos

Sistema web desenvolvido para **pré-processamento e análise textual**, aplicado à **Mineração de Textos** e ao **Processamento de Linguagem Natural (PLN)**, com foco em análise de domínio textual.

Projeto acadêmico desenvolvido no **Instituto Federal do Paraná (IFPR) – Campus Jacarezinho**.

---

## 🚀 Funcionalidades
- Configuração e ordenação dinâmica das etapas de pré-processamento
- Limpeza textual, normalização e remoção de stopwords
- Aplicação de Snowball Stemmer
- Geração de estatísticas textuais
- Ranking de frequência de termos
- Nuvem de palavras
- Comparação entre texto original e texto processado
- Histórico de análises com persistência em banco de dados

---

## 🛠️ Tecnologias Utilizadas
- Python
- Flask
- HTML5
- CSS3
- JavaScript
- MySQL
- Arquitetura MVC
- Processamento de Linguagem Natural (PLN)

---

## 🧱 Arquitetura do Projeto
O sistema segue o padrão arquitetural **MVC (Model-View-Controller)**, com separação clara entre:
- **Backend:** API desenvolvida em Flask
- **Frontend:** Interface web interativa
- **Banco de Dados:** MySQL para autenticação e histórico de análises
